# Machine photos — the stored Concurrent processor board

Nick's photographs, taken 2026-09-23 and converted from HEIC (long edge 2400 px).
Photographer: Nick DeMarco. Usable on the kiosk.

**The machine:** it was catalogued as a "3280" but is **not a 1986 3280**. It was
designed in 1993 and shipped in 1995. Its marketing name is unknown.

`outputs/2026-09-21-interdata-story/firsthand/cpu-board-full-photos-2026-09-23.md`.
In summary: an Am29C332 ALU and Am29C331 sequencer, gate arrays from LSI Logic
and VLSI, and a TI ACT8836 multiplier. Bare board 25-AAM R02, assembly 35-AAM
M04 R17. Newest date code 9515.
